# Personal Portfolio Website

## Project Overview

This project is a personal portfolio website developed to showcase my academic background, technical skills, software development projects, and professional achievements.

The website serves as a central platform where potential employers, recruiters, and collaborators can learn more about my experience and explore my work.

## Project Objectives

- Create a professional online presence.
- Showcase completed software development projects.
- Highlight technical skills and academic achievements.
- Provide an accessible contact method.
- Demonstrate frontend and backend development skills.

## Technologies Used

**Frontend**

- JavaScript

**Backend**
- Node.js

## Key Features

### Responsive Design
The website is designed to adapt to different screen sizes, including desktops, tablets, and mobile devices.

### About Me
Introduces my educational background, interests, and career aspirations.

### Skills Section
Highlights my programming languages, development tools, and technical abilities.

### Project Showcase
Displays selected projects and demonstrates my practical software development experience.

### Contact Form
Allows visitors to submit messages through a contact form connected to a backend email service.

## How to Run the Project

### Frontend

1. Download or clone the repository.
2. Navigate to `01-Portfolio`.
3. Open `index.html` in a browser.

### Backend

1. Install Node.js.
2. Open a terminal in the directory containing the backend `package.json`.
3. Install dependencies:

```bash
npm install
```

4. Configure the required email service environment variables.
5. Start the backend using the start command defined in `package.json`.

**Note:** The contact form requires a correctly configured backend email service.
